# SFDC Metadata Navigator

A Chrome Extension (Manifest V3) that provides instant fuzzy-search navigation to Salesforce metadata items directly from the browser.

## Features

- Fuzzy search across Profiles, Permission Sets, Flows, Email Templates, Page Layouts, Validation Rules, and Apex Classes
- Click a result to navigate directly to its Setup page
- Ctrl/Cmd+Click to open in a new tab
- Keyboard navigation (Up/Down arrows, Enter to select)
- Per-org index caching with manual refresh
- Multi-org support (separate index per org)
- Configurable metadata types via settings page
- Session cookie authentication (no OAuth setup required)

## Prerequisites

- Node.js 18+
- npm
- Google Chrome

## Setup

```bash
cd sfdc-metadata-navigator-extension
npm install
```

## Build

```bash
npm run build
```

This bundles the TypeScript source into a loadable Chrome extension at `build/`.

## Load in Chrome (Manual Testing)

1. Run `npm run build` to produce the `build/` directory
2. Open Chrome and navigate to `chrome://extensions`
3. Enable **Developer mode** (toggle in top-right corner)
4. Click **Load unpacked**
5. Select the `build/` folder inside this project
6. The extension icon (blue with magnifying glass) appears in your toolbar

## Usage

1. Navigate to any Salesforce org page (Lightning Experience)
2. Click the extension icon in the toolbar
3. On first use, click **Refresh Index** to fetch metadata from your org
4. Type in the search box to find metadata items
5. Click a result or press Enter to navigate to its Setup page
6. Use Ctrl+Click (Cmd+Click on macOS) to open in a new tab

## Settings

Click the gear icon in the popup footer to open Settings. From there you can enable/disable which metadata types are included in search results.

### How It Works

1. **Content Script** extracts the org ID from the active Salesforce page
2. **Background Service Worker** reads the session cookie and queries the Salesforce Tooling/REST APIs to build a metadata index
3. **Popup UI** loads the cached index and provides fuzzy search via Fuse.js
4. Selecting a result navigates the active tab (or opens a new tab) to the metadata item's Setup page

### Authentication

The extension piggy-backs on your existing Salesforce session (the `sid` cookie). No Connected App or OAuth configuration is needed. You must be logged into the Salesforce org in your browser for the extension to work.

## Troubleshooting

- **"This extension works only on Salesforce org pages"** — Navigate to a Salesforce page first, then click the extension icon.
- **"No metadata cached for this org"** — Click Refresh to build the index. This requires an active Salesforce session.
- **"Session expired"** — Refresh your Salesforce page to re-authenticate, then try the extension again.
- **Stale indicator shows** — The index is older than 24 hours. Click refresh to update it.
- **Extension icon not visible** — Click the puzzle piece icon in Chrome's toolbar and pin the SFDC Metadata Navigator extension.
